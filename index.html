Questions
Good to know.

  

    
Do I need any coding experience?
No. Every course starts at “what is a variable?” and ramps up gradually. If you already code, the later units go deep — closures, ownership, templates, concurrency and more.

    
Does the code actually run?
JavaScript lessons and the Playground run real JavaScript on your phone. Swift, Rust and C++ lessons teach through predicting output, completing code and arranging it — the same skills you use reading real code.

    
How much does it cost?
The app is free to download, and the first 5 lessons of every language are free. A single one-time purchase of $19.99 unlocks all 600 lessons and every future update. There is no subscription.

    
Do I need an account or internet?
No account, and lessons work offline. Your progress is saved on your device.

    
How long is each lesson?
About 3–5 minutes: one concept card and five short exercises. Perfect for a commute or a coffee break.

    
Which iPhones are supported?
CodeQuest is built for iPhone running iOS 17 or later.
